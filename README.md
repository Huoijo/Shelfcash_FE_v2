# ShelfCash Frontend (v2)

Production frontend rebuild for ShelfCash.

## Tech Stack

- React 19
- TypeScript
- Vite
- Vanilla CSS

## Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Typecheck and build for production
npm run build

# Lint code
npm run lint
```
